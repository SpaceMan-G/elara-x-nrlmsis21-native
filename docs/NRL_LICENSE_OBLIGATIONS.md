# NRLMSIS licence obligations checkpoint

The controlling text is `nrlmsis2.1_license.txt`; this checkpoint is not a substitute for that agreement or legal advice. It records the controls relevant to this wave:

- research, academic, and non-profit use only; commercial use is prohibited;
- the agreement and required incorporation notice are included;
- modifications carry dated notices;
- translations/derivatives remain publicly available;
- official parameter and oracle payloads are not redistributed;
- the licence's delivery obligation to the authors or NRL Code 7630 remains an owner   compliance action and is not performed by this repository-creation package.
